# 阶段交付与验证记录

## 1. 项目基础与学校数据适配

实现：TypeScript 工程、周次/授课安排解析、教学班识别、分页完整性检查、独立 UIS 连接器初版。

学校公开入口已确认使用竹云 UIS 页面；公开脚本包含账号密码、图形验证码及二次认证入口。已有登录页面提供必要课程字段。

限制：真实账号自动认证、验证码交互与云服务器网络尚未通过。连接器只能处理普通账号密码流程；遇验证挑战返回明确失败，不绕过，不清空已登记数据。发布前必须由用户在本地登录表单验证真实账号，全链路成功才能将生产 `UIS_ENABLED` 设为 `true`。

自动测试结果随阶段提交更新；测试课程均为合成数据，不提交用户账号、密码、会话或个人课表。

阶段检查：TypeScript 检查通过；7 项解析/完整性测试通过；npm 安装审计为 0 个已知漏洞。此结论只覆盖本地已实现部分，不等于 UIS 真实登录验证通过。

## 2. 数据、会话与导入闭环

实现 PostgreSQL 迁移、独立本站会话、身份哈希、查询任务隔离、导入预览/确认/去重、登记人数、同班昵称权限和不完整快照保护。

阶段检查：TypeScript 检查通过；18 项测试通过。数据库集成测试使用 PGlite 的 PostgreSQL 引擎，覆盖并发去重、幂等、隔离、过期、数据变更待审核。HTTP 测试覆盖来源校验、认证查询失败、跨浏览器任务访问和退出后会话失效。真实云 PostgreSQL 与真实 UIS 仍待联调。

## 3–4. 课表交互、考勤审核与同班名单

实现桌面周表、手机日列表、复合筛选、密集冲突展开、账号与昵称、导入预览、个人登记取消、学生反馈、管理员审核与教师变化重置考勤。

阶段检查：26 项单元/数据库/API 测试通过；3 项 Chromium 端到端测试通过；类型检查和生产构建通过。测试覆盖 300 门课程布局、20 门同时间重叠，以及从学生反馈到管理员审核的完整流程。桌面 1440px 与手机 390px 截图已检查。

端到端测试发现并修复无请求体 POST 的 Content-Type 问题；视觉检查发现并修复两节课卡片文字被 flex 压缩裁切。

实现调整：数据库直接使用参数化 SQL 与版本化迁移，避免同时维护 ORM 和 SQL 两套结构。保留 PostgreSQL 事务、约束及数据库行为测试；去除了未使用的 Drizzle 依赖。
